# Generic example: troubleshooting a web application page

> TRAINING EXAMPLE ONLY — Not product-specific documentation.

## Initial checks
1. Refresh the page once and note any visible error message.
2. Confirm the user is signed in and has access to the requested area.
3. Check whether the issue occurs on another page or only one workflow.
4. If appropriate, try a private/incognito window to isolate browser extensions or cached state.
5. Record the approximate time, page URL, steps to reproduce, and a sanitized screenshot.

## Escalation information
A useful bug report includes expected behaviour, actual behaviour, exact reproduction steps, browser and operating-system versions, and a request/correlation ID if the application exposes one.

## Safety
Do not request passwords, API keys, session cookies, or full payment details. Avoid clearing browser data if it may remove unsaved work.
